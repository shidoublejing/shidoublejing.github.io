匹配原理与设计步骤（课程要点）
  • 归一化：z_L = Z_L / Z₀ = r + jx，将负载描点于史密斯圆图（单位圆内）。
  • 判区： 若 r < 1（z_L 在 r=1 圆内）→ 采用先串后并：串联元件靠近负载，沿等 r 圆移动至与 g=1 圆相交（上下两个交点 → 两个解），再沿 g=1 圆（并联元件）移动至圆心； 若 r > 1（圆外）→ 采用先并后串：并联元件靠近负载，沿等 g 圆移动至与 r=1 圆相交，再沿 r=1 圆（串联元件）移动至圆心。 当另一种拓扑在数学上亦可行（r<1 且 g≤1）时，工具一并列出，便于对比带宽。
  • 元件换算（ω = 2πf₀）：
    串联：x_s>0 → L = x_s·Z₀/ω；x_s<0 → C = −1/(ω·x_s·Z₀)
    并联：b_s>0 → C = b_s/(ω·Z₀)；b_s<0 → L = −Z₀/(ω·b_s)
  • 验证：每个方案在 f₀ 处输入阻抗 Z_in = Z₀（|Γ| = 0，VSWR = 1），但带宽不同——用下方扫频曲线对比，选中通带（|S₁₁| ≤ −10 dB）更宽的方案。
  • 局限：纯电抗负载（r=0）无法用 L 型双元件网络实现有限匹配；r=1 边界退化为单元件匹配。
说明：① 扫频曲线假设负载阻抗 Z_L 恒定、仅匹配网络元件随频率变化（教材常用带宽近似）；② 元件均视为理想元件； ③ 本工具为教学辅助，元件值按集中参数模型在 f₀ 处精确匹配。修改输入后结果、圆图与扫频实时联动。
